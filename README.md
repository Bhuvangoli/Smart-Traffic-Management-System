# Smart City Traffic Management System

## Features
- Real-time traffic monitoring
- Alerts for congestion
- Dashboard analytics
- CSV export
- Simulation module

## Tech Stack
- Python (Flask)
- MongoDB Atlas
- HTML/CSS

## Setup

1. Clone repo
2. Create .env file:
   MONGO_URI=your_mongo_uri
3. Install dependencies:
   pip install -r requirements.txt
4. Run:
   python app.py
